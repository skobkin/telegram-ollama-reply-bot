# Investigate a separate Decision Persona

Investigate whether an optional decision-specific persona improves semantic quality or reduces latency compared with the full character prompt. Baseline must remain the ordinary full prompt; no automatic summarization or separate prompt setting in the initial interactive implementation.

Compare representative multilingual synthetic/consented test dialogs, full vs manually condensed persona, across configured System One models. Measure decision quality, action distribution, latency and context overflow; examine whether shortened prompts lose social boundaries or character-specific interests. Do not collect persistent private conversation traces. If useful, propose a separate implementation with explicit inherited/overridden settings, clear reset semantics and no implicit cloud use. Research outcome may be to keep the full prompt.
