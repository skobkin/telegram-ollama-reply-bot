# Add a terminal `say_nothing` tool

Independent of proactive interaction and System One. Let an authorized generation model explicitly end its current turn without sending a text response, including after a reaction. Add a no-argument tool following the existing registry, tool permission and event conventions. A successful tool call returns a terminal outcome to the turn orchestrator, not an ordinary result requiring a further completion. Do not invent external side effects, clear history, rollback successful prior tools, or change chat policy. No additional model request after termination; ignore pending subsequent tool calls once the terminal outcome is accepted. Execute tool calls in an order that makes termination unambiguous; inspect current parallel tool-call handling before choosing implementation.

`set_reaction` remains non-terminal in normal turns. Models may react and reply, react and call `say_nothing`, or call `say_nothing` without a reaction. Respect existing cancellation, logging, history and privacy rules. Suppress unsent buffered text and discard unfinished preview/draft via existing mechanisms; already published content is not retroactively unsent. Document any unavoidable limitation for text already delivered during streaming. Do not introduce a new durable trace. Explicitly instruct the model when silence is appropriate without making reactions imply silence.

Acceptance: terminal call ends loop with zero further requests and no unsent text published; earlier reaction remains; ordinary reaction followed by text still works; unauthorized/disabled tool calls do not terminate; mixed tool calls, cancellation, live preview cleanup and existing history behavior tested. Not a blocker for the restricted proactive React path, which independently enforces no text.
